# Results

- `hyperparameter_sweep_results.csv`: Results from the 600 hyperparameter-search runs.
- `final_evaluation_results.csv`: Results from the 50 final seeded training runs.
- `centrality_ablation_results.csv`: Matched comparisons using all four centralities, betweenness only, and betweenness excluded.
- `representative_bipartite_test_predictions.csv`: Test predictions used for the representative Bipartite GNN parity plots.

Stiffness and MAE values are reported in MPa.
