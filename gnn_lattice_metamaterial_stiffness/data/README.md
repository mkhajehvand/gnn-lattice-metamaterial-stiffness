# Data

This project uses the unit-cell catalog published by Thomas S. Lumpe and Tino
Stankovic (2021) with the article
[Exploring the property space of periodic cellular structures based on crystal networks](https://doi.org/10.1073/pnas.2003504118).
The catalog is available from the
[ETH Zurich Research Collection](https://doi.org/10.3929/ethz-b-000457598).

Download `Unit_Cell_Catalog.txt` from the ETH Zurich record and place it in
this directory before building the dataset cache.
